# Embedded Public Node API v1 Fixtures

These fixtures are release-gated conformance artifacts for the embedded public node API.

They are consumed by Rust tests in `rns-embedded-ffi` and are intended to be mirrored by first-party wrappers.

Current fixture set:

- `capability-probe.json`
- `poll-timeout.json`
- `restart-epoch.json`
- `gap-restart-signaling.json`
- `truncation-reporting.json`
- `extension-ids.json`
