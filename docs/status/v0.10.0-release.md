## Artifact verification

- The 20 original release assets were downloaded from the release and verified
  against `SHA256SUMS.txt`; every checksum matched.
- The performance JSON, HTML, and raw bundle were verified against the release
  `SHA256SUMS`; all three checksums matched. The generated dataset records five
  interleaved comparison runs, two resource runs, and 1,000 resource iterations.
- The release regression gate passed with geomean throughput `1.008x`, CPU
  `1.005x`, and peak RSS `1.086x` versus the same-runner v0.9.1 baseline; no
  warnings or failures were emitted.
- Representative Linux archive attestation verification passed with the release
  workflow signer and `refs/tags/v0.10.0` source reference.
- Linux, macOS, and Windows archives contain the expected host tools and
  README; extracted Linux binaries report `lxmf-rs 0.10.0` and are static-pie.
- The release contains 35 assets: the original platform/package/SBOM assets,
  11 independent interoperability assets, and four performance assets (JSON,
  HTML, raw evidence, and the performance checksum file).
