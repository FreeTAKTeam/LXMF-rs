# v0.13.0 release candidate (in progress)

The candidate starts from remote `main` at
`feb5d6cf35ff47c7d7e79b1ee7e3c27ad6a1110d` and targets the exact Python
Reticulum 1.5.5 tag at `7f2b3b9b524c9386316379af1313b43a5e4f7a5d`.
This is a changed-feature update, not full Reticulum parity. The active 1.5.2
reference and historical #605 1.5.4-dev feature pin remain unchanged.

Named interface attach/detach/reload is not yet implemented. Existing
`set_interfaces` acknowledges queue admission rather than local startup and
must not be advertised as that feature. The management feature's release scope
must be resolved before final notes or publication. Physical, client, and
public-network acceptance in #616 is outside this feature-update gate.
