# v0.12.0 release candidate

The candidate is [PR #642](https://github.com/FreeTAKTeam/LXMF-rs/pull/642),
based on the tested RNS 1.5.2 release reference. It adds only the scoped
pinned RNS 1.5.4-dev feature changes described in the
[delta ledger](rns-1.5.4-delta.md); inherited parity follow-ups and #616
physical/client/public-network acceptance remain separate.

| Gate | Candidate evidence |
| --- | --- |
| Version alignment | `VERSION`, all 17 public crates, local dependency requirements, and lockfiles are `0.12.0`. |
| Local release gate | `cargo xtask release-check` passed on the candidate tree on 2026-09-27, including dry-run crate packaging, Miri, software soak/mesh, reproducible build, embedded footprint, architecture, boundaries, and module size. |
| Binary smoke | `cargo run -p rns-tools --bin rnx -- e2e --timeout-secs 20` passed direct, opportunistic, propagated, discovery, and compatibility flows. |
| Reference pins | `python3 tools/scripts/check_python_reference_pins.py --self-test` passed; active 1.5.2 and forward 1.5.4-dev commits are unchanged. |
| Hosted exact-head checks | Require CI, Verify, and Independent interoperability to pass on the final PR head before merge and tag. Use the live PR checks as authority; earlier heads do not qualify. |

## Publication decision

**Conditional recommendation:** publish `v0.12.0` only if the final PR head
passes the hosted checks above, the reviewed change is merged without added
content, and the tag points to that exact merged commit. Otherwise hold the
release and fix or explicitly resolve the failed gate. Verify public assets,
checksums, provenance, OCI image, and matching crates.io versions after the
immutable tag; record that evidence separately. This candidate does not
certify the outstanding physical or full forward-parity matrix.
