# Plan

Prepare and publish `v0.9.8` from a reviewed post-`v0.9.7` candidate. The patch release should carry the merged resource-transfer, MTU, propagation, SDK deadline, lock-scope, metadata, cancellation, and compression fixes on `main` while preserving the parity limits documented by the matrices; this document is an execution plan, not a release publication.

## Scope

- In: version alignment, release notes and evidence, roadmap/matrix reconciliation, exact-SHA local and hosted gates, pinned-Python interop, RC/final tags, the `release` publication branch, crates.io packages, native bundles/checksums, and rollback evidence.
- Out: new parity implementation, changing the documented 115 partial Reticulum inventory, claiming unverified third-party/hardware/public-network compatibility, or publishing directly from this plan branch.
