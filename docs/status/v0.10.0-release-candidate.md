## Tag-triggered evidence boundary

This PR prepares but does not create the tag. Release archives and packages,
SBOMs, checksums, signing/attestation state, OCI publication, and the versioned
performance dataset can only be verified after an immutable candidate tag is
authorized and pushed. They are not prerequisites for declaring the PR head
ready to tag, but they are prerequisites for promoting the candidate to a
stable release.
