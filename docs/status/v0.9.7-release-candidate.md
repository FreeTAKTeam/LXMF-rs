# v0.9.7 Release Candidate

Last updated: 2026-08-01

This ledger records release evidence for the v0.9.7 candidate. The current
candidate is based on `origin/main` at `709cff55`; v0.9.6 remains the published
stable baseline.

## Candidate scope

- Merged multi-service identity and additive SDK v2 identity operations.
- RPC, authentication, private-storage, crypto-safety, RNS 1.4.2 parity,
  resource, propagation, and transport-worker hardening merged after v0.9.6.
- The six v0.9.6-to-v0.9.7 transport/LXMF fixes retained in the candidate
  history.

## Open PR audit

PR #542 merged into `main` at `709cff55` on 2026-08-01. The candidate was
refreshed from that exact merge before the final gate run.

The pinned reference conformance job reproduced one known reference-only
failure in boundary-mode recursive path-request gating, and the live remote
relay suite reproduced one Python-to-Rust delivery failure after two
complementary relay cases passed. These remain documented partial parity rows
for v0.9.7; the hosted workflow defers only those named cases and continues to
gate on the remaining reference suite and Rust interop stages.

## Refresh notes

The prior local candidate was preserved before refreshing from origin because
`origin/main` advanced substantially after v0.9.6, including the merged #504,
#507, #508, #510, and #542 work plus additional parity and safety fixes. This
branch is rebuilt from the refreshed mainline so the release evidence can be
tied to one exact tree.
