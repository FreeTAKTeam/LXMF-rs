## Scope review

The candidate is limited to the post-v0.9.7 fixes already present on
`origin/main`: resource-transfer request windows and scheduling, negotiated MTU
sizing, propagation bounds and failure reporting, SDK deadline enforcement,
lock-scope preparation, split-resource metadata, cancellation handling, and
compression. No new parity implementation is included in the release work.

The maintained parity boundary is unchanged: seven LXMF module rows are
complete for named software scenarios, while the RNS 1.4.2 inventory remains
1,695 complete, 115 partial, and 1 not applicable.

  third-party client claims remain outside this software release gate.

  v0.9.7 SHA, then yank only packages proven to have been published in error;
  package rollback never rewrites crates.io history.
