# Migrating to v0.10.0 and RNS 1.5

The `0.10.0` minor release is source-breaking under the workspace's pre-1.0
versioning policy. It aligns the Reticulum surface with Python RNS 1.5.0 and
adds transport status and discovery fields.

## Rust source changes

- `DiscoverableInterface` now requires `operator_lxmf_address: Option<[u8; 16]>`.
- `InterfaceSharedConfig` now includes
  `discovery_lxmf_address: Option<String>`. Prefer
  `..InterfaceSharedConfig::default()` in struct literals so future optional
  fields do not require source changes.
- `ReticulumRuntimePolicy` now exposes `network_identity_path` and
  `inbound_queue_limits`. Prefer `ReticulumRuntimePolicy::default()` and set
  only the policy fields your application owns.
- Typed daemon status and SDK/RPC response structs include new optional
  queue, traffic, violation, link, and medium-timeout telemetry. Consumers
  should regenerate schema-derived clients and continue ignoring unknown
  fields when decoding JSON.
- Channel payloads above `u16::MAX` are rejected because the Channel wire
  envelope carries a two-byte payload length.

## Daemon configuration

Encrypted RNS 1.5 interface discovery is network-scoped. Configure the same
identity file on each participating node:

```toml
[reticulum]
network_identity = "/var/lib/reticulumd/network.identity"
```

When `discovery_encrypt = true`, publication is skipped unless this identity is
configured. Do not copy a node's normal daemon identity for this purpose; the
network identity is a separately managed shared trust root.

Reticulum IFAC authentication is not implemented in this release. The daemon
now rejects `ifac_size`, `network_name`, `networkname`, `passphrase`,
`pass_phrase`, `ifac_netname`, and `ifac_netkey` instead of accepting settings
that would not authenticate packets. Remove those fields or keep the node on a
release that implements the required IFAC security boundary.

Queue lengths use the RNS 1.5 names under `[reticulum]`:

```toml
[reticulum]
qlen_in_data = 4096
qlen_in_announce = 256
qlen_in_pr = 256
qlen_in_il = 128
```

Omitting them preserves the defaults shown above. Values must be positive.
